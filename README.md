# Canine oral microbiome manuscript resources

This repository contains collaborator-supplied figure materials and the
current reproducible workflow for the canine oral microbiome manuscript.

## Reproducible workflow

The complete, GitHub-ready analysis package is in [`workflow/`](workflow/).
It includes:

- figure-specific input cohorts and the analysis code;
- Hoffman2 Slurm submission scripts;
- saved analytical intermediates and a render-only workflow;
- title-free final figures in 300-dpi PNG and vector PDF formats; and
- detailed installation and reproduction instructions.

Begin with [`workflow/README.md`](workflow/README.md).

The historical top-level figure folders are retained unchanged for provenance.
